Real game pipeline · ref size 512 · output 512x512 · 2 edits per sword (white-bg vs transparent)
Each sword is rendered through the carry pipeline twice. white-bg ref flattens the alpha to white pixels (this is what prepare_reference() in pipeline.py does today). transparent ref keeps the alpha channel intact. Same prompt, same LLM description, same player reference, same generation seed (random) — the only variable is the reference image background. Compare side-by-side to judge whether flattening to white affects edit quality.
